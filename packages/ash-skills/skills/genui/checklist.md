# 发前自查

逐条过，有一条不过就改，改完再发。发出后回包的 `hints` 会再查一遍其中能机器查的几条。

**必须过**
1. 主角一眼能找到：全卡只有一处 `h1`/`h2`，它就是主人问的那件事。
2. 根 `Column` 没有 `background`/`padding`/`cornerRadius`，外面没有再套 `Card`。
3. 留白用容器的 `gap`：根 14，标题区 2，几行 8；没有两块贴在一起，也没有给每个子元素各写 `margin`。
4. 文字里没有 emoji；`Icon` ≤ 1；`Badge` ≤ 1；`accent` ≤ 2 处；没有十六进制色。
5. `primary` 按钮 ≤ 1；只是看的卡没有按钮。
6. 所有数字都来自查到的数据，没有编的。
7. 标题一行；没有超过三行的段落；单元格 ≤ 8 字。
8. 气泡里的话 ≤ 40 字，不重复卡片内容。
9. 要密码用了 `human_form` + `secret`。
10. 行情涨红跌绿；股价、体重这类走势写了 `min`，不是贴底的平线。

**最好也过**
- 从上到下读一遍，顺序就是主人想知道的顺序。
- 能删的再删一块：删了主人也不会问的，就删。
- 同类的行长得一样（同样的字号、颜色、宽度、间距）。
- `ChoicePicker` 的 `value` 是数组。

**发出以后**
- 回包 `problems`、`hints` 为空；不为空就 `human_card_update` 改原卡。
- `card.preview` 看一次图：挤、截断、折行、对不齐、平线图，有就改。
