# 认字和说话

两个能力都在主人的手机上（`device:<手机的 id>`，id 从上下文的设备列表拿），**离线**跑，不把图片或文字发到任何云：便宜，可以常用。

## 两个能力

| 能力 | 做什么 | 要点 |
|---|---|---|
| `ocr.read {path 或 data, max_side?, min_score?}` | 读出图里的文字 | `path` 是手机共享存储里的图片（`/sdcard/...`），`data` 是 base64（约 10 MB 以内），二选一；返回 `text`（按阅读顺序，一行一行）和 `blocks`（每行的 `text`、`box` = [左, 上, 右, 下]（图片像素）、`score`）。一个模型同时认中文、英文、日文和多种拉丁字母语言，不用选语言 |
| `tts.speak {text, play?, lang?, voice?, rate?, pitch?}` | 把文字变成语音 | `play: true`（默认）在手机上直接念出来，念完才返回；`play: false` 做成 WAV 文件放进 `/sdcard/Ash/tts/`，返回 `path`，你拿去发给主人或存起来。中文文字念中文，其他念英文，`lang`（如 `zh-CN`、`en-US`）可以改。文字最多 4000 字 |

## 做法

1. **读图里的字**：图在相册里，`media.list` 给的 `path` 直接传；图在你的工作区里，要先放到 `/sdcard/...` 下，或把内容当 `data` 传。要读**此刻的屏幕**：`screen.screenshot` 存成文件，再把返回的路径给 `ocr.read`（不用再逐个读元素）。
2. **第一次用要下载模型**（约 140 MB，只一次，存在 Ash 自己的私有目录）。这一次可能要几分钟，调用会一直等，超过十几秒先返回回执（`status: accepted`），用 `await_result` 收，不要重复调用；中断了会接着下。之后每次几秒，模型 90 秒没人用就从内存里放掉。
3. 结果先看 `text`；要知道哪行在哪里（比如要去点它）才用 `blocks[].box`，坐标是**图片**像素，换成屏幕位置要按图和屏幕的比例算。
4. `tts.speak` 想念给主人听就 `play: true`；一句话一次，别一口气念几千字，主人没法打断。要留存或转发才 `play: false`。

## 好的样子

主人说「看看这张收据一共多少钱」。`media.list {type: "image", name: "收据"}` 找到图，拿它的 `path` 调 `ocr.read`；`text` 里读到「合计 ¥ 1,284.50」，回「合计 1,284.50 元」，并说是从哪一行读的；有一行 `score` 只有 0.6，提醒他「这一行我不太确定：…」。没有把图和文字发给任何别的服务。

## 常见错误

- 对一张大图直接读，小字漏了：试 `max_side: 1280` 或 `1600`（慢一些）；整张图是密密麻麻的小字，先裁成几块再读。
- 把识别结果当百分之百准确：金额、号码、日期这些要紧的东西，看 `score`，低的告诉主人并请他确认。
- 手写体、艺术字、很斜的照片读得差，这不是调用错了，直说读不清，别编。
- 路径不在共享存储里（`unavailable`）：先把图放到 `/sdcard/` 下，或用 `data`。
- `tts.speak` 返回 `unavailable`：手机的朗读引擎没有这种语言的语音，如实告诉主人（可以在系统「文字转语音」里装语音包），不要反复重试。

## 怎么核对

- `ocr.read` 结果的 `width`、`height` 和图一致；`ms` 里第一次比后面多出模型下载和加载的时间。
- `tts.speak` 的 `play: false` 返回的 `path` 能在 `/sdcard/Ash/tts/` 里看到，`duration_ms` 大于 0。
- 失败信息里有原因：`forbidden`（还没给存储权限，用 `config.permission.request {name: "photos"}`）、`unavailable`（模型下载不了、没有这种语音）、`too_large`、`timeout`，照实转述。
