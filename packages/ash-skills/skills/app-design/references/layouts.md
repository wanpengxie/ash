# 手机屏型骨架

通用：360dp 宽；系统状态区、56dp 顶栏、可滚动内容、系统安全区。页边距16，组间20–24，组内8–12，成对文字4。标题22/30，行标题15.5/22，副标题13/19；直接用 AshTokens 的对应样式。组件高度按内容增长，不锁死文字盒。

| 屏型 | 从上到下 | 动作与尺寸 |
|---|---|---|
| 内容首页 | 应用名与轻导航 → 有身份的hero（大日期/整体画面/当前事件）→ 日程轨道、内容卡或真实进展 → 一个轻量主动作 | 时间与状态进入内容；不要用圆角设置组装满首页。任务可借Things Today，设备可借查找/家庭的物件画面 |
| 详情 | 返回与更多 → 事项/对象的身份hero → 现在发生的事/结果 → 进展轨迹或来源 → 下一步行动 | 配置放二级抽屉；能力呈现为能做的事，别把详情再画成属性设置表 |
| 分组设置 | 返回与标题 → 组标题 → 同类设置行 → 简短组尾说明 | 单行56、双行72起；右侧值/箭头/开关三选一；危险操作独立分组、确认对象 |
| 对话/信息流 | 对象与状态 → 按时间组织的真实往来 → 持续可用输入区 | 头像与名字分清发起者，委托与答复成串；长文折叠但可读原文；不以气泡装所有配置 |
| 仪表盘 | 当前结论 → 需要我处理 → 进展/最近结果 → 次要入口 | 不凭空制造数字或仪表；无真实聚合数据则改用分组列表 |
| 一屏流程 | 返回/取消 → 当前目标与短说明 → 当前步骤内容 → 主按钮 → 状态反馈 | 只显当前阶段；命令/代码可复制，批准前看清对象和访问范围；等待不能伪装成功 |
| 空状态/失败 | 原有导航 → 一枚克制图标 → 具体状态 → 一句下一步 → 一个动作 | 无数据和加载失败分开；失败能保留旧内容时在原内容旁提示，勿整页清空 |

选择规则：重复对象用列表，改偏好用设置，办一件事用流程，追一件事用详情。选定骨架后先用真实长标题试一次，别拿「项目一/测试设备」填版。五种筛选若标签太长，用范围选择菜单；不要挤成五个短到看不懂的标签，也不要制造五个全局底部导航目的地。

「活的」靠真实事件：doing可以用不定进度，已完成数可算真实完成比；没有分步数据不画确定百分比。连接脉冲表示当前已证实的连接，不能冒充正在执行工作。没有电量、在线时长、文件读取数就不展示。动效尊重减少动画。

## 任务首页：结构化日程

主人明确选这种骨架时：小日期+完成环 → 三个可点的责任数字块 → 无时间事项的紧凑区 → 有时间的时刻轨道与当前红线 → 可横滑的工作/等待卡 → 底部输入栏。数字、时间、勾选和进度是主要语汇，不用一句Ash摘要替代它们。

分类色表达不同责任，不作装饰；等待卡可用完整的语义色轮廓和一个直接行动按钮。没有分步数/预计时间不填百分比或ETA；没有已存在的主线关联不造分类名或新存储。时间轨道挂提醒点，不把提醒时刻假装成有起止时长的日历事件。
