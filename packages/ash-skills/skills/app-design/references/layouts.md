# 先选表达，再选屏型

通用：360dp宽，状态区、56dp顶栏、滚动内容、安全区；页边16、组间20–24。标题22/30、行标题15.5/22、正文15/24、副文13/19，沿用项目令牌。先画区域和目光顺序，再填真实中文。不以hero、底栏或时间轴作为每个App的先决条件。

| 要判断什么 | 适合的结构 | 人的行动 |
|---|---|---|
| 回来后发生什么 | 小变化摘要→待处理→当前工作→后续 | 处理重点，进入同一对象 |
| 哪个方案合适 | 约束→对齐比较表/图→选项与后果 | 选择、改条件、暂缓 |
| 谁在做什么，卡在哪 | 责任与执行关系图/分栏，异常突出 | 追问、暂停、接手 |
| 什么时候轮到我 | 时间轴/周带；无时间单独紧凑区 | 自办勾选、改时间 |
| 是否真的完成 | 产物预览→差异→验证范围→未确认 | 检查、接受结果、具体纠正 |
| 能否用，允许什么 | 连接/能力/授权分开编码，受影响工作相邻 | 允许、收回、处理连接 |
| 我要精确改一处 | 同对象抽屉，原值与变化明确 | 改、保存、取消；回原空间 |
| 修改稳定偏好 | 二级分组设置 | 开关/明确选择，不做应用首页 |

详情先身份与当前事实，再证据或产物、行动、收起的经过；不是把属性表铺满。底栏只放长期目的地；详情返回后保留原空间、筛选、阅读位置与未提交内容。

进行中按信息选择：有可确认阶段用节点；无阶段用最近活动和最后确认时间；未知直说。过程停止不自动代表目标完成。时间轴相邻事项不能互盖：必要时局部撑开、统一刻度与当前线的排布，不能缩触控或伪改时刻。

空/失败保留原外壳和已知内容，说明缺什么及下一步。不要为图形饱满造电量、持续时长、历史、ETA或工作计数。
