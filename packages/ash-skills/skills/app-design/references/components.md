# Ash 原生组件规格

颜色/字体/圆角唯一来源：仓库 `design/app/tokens.json`，Android 对应 `AshTokens`，组合组件放 `AshUi`。页面不用新的调色板。现有暖背景属于品牌上下文，应保留；不照参考把全局颜色换掉。HTML 从同一 JSON 导出 CSS 变量。文字用 ink/text/text2，浅 text3 不放必要信息；使用前量实际底色的对比度。

现有可复用：text、vstack/hstack、button、rounded、card、sheetBackground、AvatarView、LetterAvatarView、AshSwitch。下列是待补或需统一的组合件规格，交施工者补到 AshUi；此技能不自动改 Android。

| 组合件 | 规格与状态 |
|---|---|
| Device/MemberRow（用于选择器或二级管理） | 16dp横边距，40–48图标/头像，间距12，弹性标题区，右侧状态和18箭头；72–88高。在线/离线写文字。长名字最多两行，状态不截断 |
| TaskRow（用于紧凑列表，不作首页唯一骨架） | 左48触控区内22完成框，中间标题与时间/责任，右侧整行开详情；80起。本人可完成，agent事项的操作按原权限；不将待做显示成执行中 |
| SettingGroup/Row | surface底、16圆角、无外阴影；行内16，行高56/72；组内分隔线从文字起。整行可点，右值最多约10字，长值另起副行 |
| SwitchRow | 标签可换行，右侧AshSwitch维持至少48触控；说明放标签下；切换结果只用真实响应，失败保留可继续入口 |
| ScopePicker | 2–3个短范围可分段，每项48触控；更多或长名称用当前范围+下拉菜单，选中项加勾。不能用假导航隐藏原功能 |
| BottomAction | 页边16、上12下安全区，52高、12圆角，一个PRIMARY；内容底部预留同等高度。次动作放独立列表行或菜单 |
| EmptyState | 48中性图标、标题17、说明14、间距12–20、一个52高动作；不放插画墙和口号 |
| InlineStatus | 一句真实状态和可选48触控动作；失败不遮挡内容，不挤焦点；恢复后移除。保存与提醒安排失败分开 |
| TimelineRow | 左时间或状态点，右具体动作+发起者；两行起，不用彩色大卡片；需证据时整行打开来源 |
| Sheet/Form | 顶部把手可省、标题22、关闭48、字段组72起、底部单一确认；系统日期/时间选择器，负责人为明确单选列表，取消不更改 |

线性图标来自 `design/app/icons/`，22dp、1.8dp线宽；不要临时画另一套或用字符替代。截图系统状态区可用中性示意，勿将其算为新增业务图标。

动效只沿用 motion 令牌做状态与页面转换，系统减少动画时直接完成。html演示局部数据不连接真实中枢；写清这一边界，施工仍使用已有状态和接口。

## 应用内容的组合件

- TodayHero：大日期（display字号可在36–64sp表达日号）、月份/星期、真实完成数或完成比、一句来自当前任务状态的小结。小结可由确定性文案组成，不假称Ash新说了一句话。它占首屏约四分之一，不做满屏宣传。
- ScheduleTrack：左侧时间/今天内，右侧有身份的事项；细轨道放卡外、用中性色，不是彩色左边框卡。时间未知写未定，不强排出虚构顺序。
- WorkCard：真实头像、具体事情、实际状态与一条进展。doing仅用不定进度；有实际分步数才用百分比。不加一排编辑按钮或常驻右箭头。
- DeviceScene：既有设备图标或简单原生几何构成物件画面；可用连线/脉冲表示已证实的在线关系。它不是地理位置或网络拓扑数据，不能暗示未提供的定位能力。
- DeviceCard：设备名字、可辨认的设备画面、当前状态/一条真实变化、能力影响；电量/任务/在线时长仅数据已有时出现。未知就用连接与能力的诚实表达，不为画面感加后端采集。

各应用可从已有you/her等令牌选择自己的主题角色和图形语言，但不另造调色板。主焦点与主动作构成少数强调，内容区以中性为主。设置分组行保留在更多、配置抽屉和二级管理。
