# Agent 原生应用设计

**GUI = 信息的高效、丰富呈现 + 决策的快速操作。** 事情的结果、时间、责任和依赖没变；变的是分工：agent 记、做、等、汇报，人理解局势、指挥、决定、验收和纠正。监督与决策是重心，仍保留对象的直接编辑、暂停和接手。语言表达开放意图与例外，GUI 表达状态、关系、比较和精确控制；不把应用退回对话列表。

## 设计师三部曲

先读任务、现有能力与 [TASTE.md](TASTE.md) 指向的共享口味。理论要作用于具体材料，不能单独产出界面。已有材料只有具备行级来源和重组证据才可复用；抽象研究不替代前两步。项目与本次授权优先于模板。

1. **理解旧世界**。逐应用拆出真实对象、属性、状态、操作、流程与视觉/动效/文案规范，另采集系统规范。**产出**：带稳定元素ID、主来源、截图/操作证据的具体材料。**检查**：区分官方值、截图像素测量、项目建议；没测过不报数值，不只列品牌或照搬首页。成熟产品的领域结构也是可继承材料。
2. **按新原则逐元素重构**。读[十透镜方法](references/reconstruction.md)，每个旧元素依次回答角色、语义、接口、关卡、各面/账本、身体多设备、上下文、注意力时间、呈现、简洁与证据。**产出**：每行回指旧ID的旧元素→新归属表、新领域模型/领域设计规范，以及对已有稿件的实质差异和接口缺口。**检查**：十问有具体答案；保留/退化/消失/新增有依据；允许推翻现稿，不倒推给旧稿找理由，不借缺口授权新机制。
3. **出统一新规范，再画应用**。写可检查的领域/视觉/动效/文案/组件细则，具名令牌、正常/加载/空/错、每条正反例；核心规格见 [设计规范](references/design-spec.md)。**产出**：规范与图例→[共用组件](references/components.md)→[应用地图](references/app-map.md)→360×800dp HTML/PNG与每屏划区动线→真实字段/按钮BUILD-MAP。**检查**：地图先于单屏，先划区后填内容；每屏按规范ID验。手感借成熟产品，手势有可见入口，不为拖动造新排序。领域示例与本次接口可施工图明确分开。

## 八条判断原则

1. **世界模型与执行关系分开**：负责不等于亲自做，委托不等于无限授权，停止一次运行不等于取消事情。
2. **语言启动与修正，GUI承载对象**：文件、报价、差异、时间可看、比较、直接改，不把它们压成一串消息。
3. **支持离开与回来**：首屏回答有什么变化、什么需要我、接下来怎样；不用重读执行日志才能恢复上下文。
4. **决定带依据和后果**：选项、关键差异、代价、影响范围和可逆性靠近动作；一句「是否同意」不够。
5. **自治按事情分配**：已有授权内连续工作，实质越界或人的判断才打断；保留编辑、暂停、接手及适用的撤回。
6. **完成能验**：产物、改变、验证和未确认范围可检查；执行结束、产物生成、现实目标达成分开，不强迫所有低风险事人工验收。
7. **关系与比较带来丰富**：网格、对齐、对象身份、异常和层级组织信息；有阶段证据才画阶段，有可测分母才画百分比，有可靠估计才写ETA。
8. **外壳稳定，局部按需表达**：导航、对象身份、权限语义和关键动作可预测；生成式比较表和选项只服务当前问题。

## 执行与交付

- 正文对比度≥4.5:1，触控≥48×48dp；必要时间和状态不裁，内容可滚，固定栏不遮挡。用项目令牌，不为塞内容缩字。
- 设置页列对象，应用页讲发生的事。分组设置只用于二级配置；不过度极简到删掉必要信息。不用emoji做图标，不堆文字链接、说明或无依据数字。
- 图形服务理解：头像表达执行者，连线表达真实关系，插画表达对象，颜色同时配文字。未知不补编；动效解释变化并尊重减少动画。
- 保存、投递、执行、验收按事实说话；完成/取消不覆盖原说明。常见失败保留内容和一个可继续动作，不借设计造低频完备机制。
- 分别验模型、交互、视觉。按 [独立复核清单](references/review.md) 打开真实PNG、走主路径，再由指定验证者给 `done/needs_work`；没验证者如实待验，不自签。
- 交付规范/正反例、地图、每屏源文件/PNG/动线、来源假设、现有与提案差距、修订与未验项。设计通过不等于主人认可、后台接通或Android/真机完成；按本次已授权的评审与施工流程推进，不重复索取已有批准。
