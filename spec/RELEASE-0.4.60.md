# 0.4.60 — 五个原生系统应用

本次将任务、设备、团队、Ash 和 Codex 从旧入口整理为独立原生应用，沿用冻结的 v6 设计与真实中枢能力；没有补造候选服务、工作关联或执行进度。

## 用户可见变化

- 任务：分清你的待办、Ash／帮手负责的事和提醒安排待补齐；直接编辑同一事项，添加时选择提醒，保留原说明和来源。
- 设备：接入批准与实际连上分开；设备能力、电脑文件命令和审批边界明确；离线恢复保留原诊断、升级与中转站入口。
- 团队：先看原交付和成员手上的事，再看配置；向原成员追问时保留原委托上下文，不把帮手回答当成已核验结果。
- Ash：共享承诺直接打开同一任务；具体事实可直接纠正，保存前读取最新完整文件；保存、回应和实际执行分别表达。
- Codex：本次批准绑定电脑、会话和请求；结果保留真实文件记录与原汇报；运行中才提供暂停，并等待电脑实际确认。

五个应用共用稳定导航和状态槽。保留原输入框、普通草稿、精确消息核销、阅读位置与键盘整块平移；不以刷新重建正在编辑的页面。
