# 广泛调研技能交接

交付一份 DSH 格式技能及可复现的真模型语言夹具。技能规定：先限定问题和比较口径，再把任务拆成可独立核对的小题；返回项统一记录范围、状态、发现和来源；失败只重试一次；汇总时重判覆盖，不把计划、未返回内容或相互冲突的记录当成已核实结论。

`live.json` 是 `deepseek-flash` 的三条可见答复，包含输入、结束原因、技能 SHA-256 和简单自动标记。最终样本全部正常结束、标记为零；作者逐条查看后，观察到：

- 规划样本只列四个待查小题，补充的人数、地区与时间口径标作假设，没有编造来源或已启动的执行者。
- 部分结果样本把 A/B 有价而 C 缺价的成本题归为部分核实；覆盖为 0/4 已核实、2/4 部分核实、1/4 失败、1/4 待返回，并注明提供的记录未独立复核。
- 冲突样本并列保留周六／周日两种说法，把报名数与实际出席数分开；覆盖为 0/3 已核实、2/3 部分核实、1/3 未完成。

三个样本的材料是合成测试输入，没有实际联网搜索、启动研究子任务或核验公开来源。这验证的是模型按技能处理计划、格式和缺口的语言行为，不能作为任何真实市场或活动事实。开发抽检曾出现把上游误标“完成”的不完整结果提升为“已核实”的情况；技能已补充重判规则，但最终这组样本不证明对所有错误上游标签稳定免疫，请非作者据此追加反例检查。

复现真模型样本时，运行 `tools/spikes` 中本卡的抽检脚本，并在进程环境中安全提供 `ASH_CONTENT_API_KEY`；脚本没有密钥便不会调用模型，也不会保存密钥或隐藏推理。`originality.json` 记录技能与本报告对 465 份私有参考文本的逐段整文件比对，阈值为超过 12 个规范化字符，无命中；输出没有参考原文或路径。F-C07/F-C10 仍待非作者签字。
